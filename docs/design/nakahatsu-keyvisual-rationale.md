## 2. 共通点と違い

| 観点 | 観察された傾向（社） |
|---|---|
| 比率 | 3:2前後が多い（01_Pentagram, WolffOlins, Zypsy 大判）。16:9に近い（Lippincott, Takram 約1.9:1, Landor）。縦長2:3は Collins のみ |
| 背景 | 作品ごとの**平面の単色**が主流（01_Pentagram, Landor, A2/SWHK）。実景の写真は WolffOlins, Pentagram, Zypsy。**グラデ地**は Zypsy の ZettaJoule/Captions, DesignStudio ホーム, FutureBrand のヒーロー帯 |
| デバイス | **ほぼ出さない**（Pentagram, Saffron, Wolff, Collins, Jetset, A2/SWHK, Lippincott, Landor, FutureBrand, Branx）。出すのは **Zypsy**（実景のノートPC/モニター+別カードのスマホ）と **Takram**（WAVEBASE等のUI画面）のみ |
| PC+SPの組み方 | Zypsy だけが両方を見せる。**同じフレーム内で重ねず、別カードに分けて離して置く**（ZettaJoule）、または**スマホ1台を中央に置く**（Captions） |
| 角丸 | **0が多数**。あっても約8px（Collins, Landor）。Play のヒーロー内の写真だけ約16px |
| 影 | **ほぼなし**。例外は実物写真が持つ接地影（A2/SWHK の本）と、Zypsy の実景写真内の自然光 |
| 余白 | 一覧は画像の間が広い（Pentagram, Takram, Zypsy）。詳細は2カラムで左を空ける（DesignStudio, Branx, Saffron） |
| 文字 | 画像の**外**に置くのが基本（キャプションは下）。画像内に大きく文字を入れるのは、ロゴそのものが作品のとき（Doris Duke, Capacity, Linktree） |
| キャプション | **太字（または黒）のタイトル+灰色の小さな補足**の2段が最多（Pentagram, A2/SWHK, Takram, Zypsy） |
| 色の抑制 | 一覧全体の**無彩色の地+作品の色だけが色**（Pentagram, Takram, Zypsy）。ページ自体が派手なのは DesignStudio, Landor, Saffron |

[推測] 事例の主役が「ブランドのロゴ・立体物」の会社はデバイスを出さず、主役が「画面（UI/Web）」の会社（Zypsy, Takram）だけがデバイスを出している。中初はWebサイトなので、後者が参照先として適切。

## 3. 河野さんの美意識との照合

出典: `Visual Design Principles.md` と `docs/architecture/design-system.md`（§5.6, §5.7, §5.8）。

| 河野さんの言葉 | 照合 |
|---|---|
| 「ドロップシャドウ濫用、3D風ボタン、過剰なグラデーション」はNG（§4） | 14社のうち影・3D風が目立つのは Lippincott の Danaher の立体ロゴ程度。**影を使わない社が大多数**なので、影なしは「弱い」ではなく業界の標準 |
| 「一律的・無個性なテンプレ感のレイアウト → NG」（§3.1） | Zypsy の「ノートPC画像のテンプレ」はテンプレ感に近づく。**実景に置いた実機写真は作れない**ので、同じ効果を狙うと安っぽいモックアップになる。[推測] |
| 「ポートフォリオ: 静けさ・余白・タイポ頼り」（§2） | **A2/SWHK、Experimental Jetset、01_Pentagram、Takram** の一覧が最も近い。単色地+余白+タイポ、キャプションは小さく控えめ |
| 「枠・カード・角丸ボックスでの囲み」はNG（図解の文法 §6.4） | 図解の話だが、サムネでも**角丸を大きくしない**方向と整合。既存の `rounded-media`（8px）は Collins/Landor と同じ水準で妥当 |
| 「AIが作った感じで気持ち悪い」（§4） | グラデ背景+浮遊パネル（Zypsy の Captions, DesignStudio ホーム）は**AI感が出やすい型**。[推測] 避けるべき |
| design-system §5.6「影は付けない」、§5.8「ヒーローは `aspect-[8/5]`、地色は `bg-surface-muted` か `bg-surface-raised`」 | 14社の観察と矛盾しない。**既存ルールを変える根拠は見つからなかった** |

## 4. 中初のサムネ/ヒーロー（PC+SP、2000x1250、8:5）への具体ルール

各ルールの「根拠フレーム」は観察したフレーム名。**推測を含むものは明記**。

1. **背景は単色1色。グラデ・実景は使わない。地色は `bg-surface-muted` か中初のブランド色を薄めた1色。**
   なぜ: 単色地は作品の色だけを際立たせ、河野さんのNG（グラデ）にも触れない。
   根拠: `01_Pentagram / homepage_desktop.png`（Doris Duke の単色カード群）、`07_A2SWHK / work_page_desktop.jpeg`（薄灰の単色地）。

2. **PCとSPは重ねず、同じ地の上に並べて置く（PCを大きく、SPを小さく、下端をそろえる）。**
   なぜ: 重ねると隠れる部分が出る。並べれば両方の画面が全部読める。
   根拠: `12_Zypsy / work_desktop.png`（ZettaJoule はPCとSPを別カードに分けて離して配置。[推測] 同じカード内で並べる形に翻訳）。

3. **デバイスの枠は付けない。画面のキャプチャを角丸8pxで切り抜いて置く。**
   なぜ: 枠付きモックアップは「テンプレ感」の典型。枠なしなら中身（実際の画面）が主役になる。
   根拠: `11_Takram / projects_index_desktop.png`（WAVEBASE等のUIは枠なしの画面を地に置く）、`04_Collins / homepage_desktop.png`（角丸約8px）。

4. **影は付けない。画面と地の境目は、地との明度差で作る。**
   なぜ: design-system §5.6 の規則どおり。白い画面を白に近い地に置くと縁が消えるので、地は画面より少し暗くする。
   根拠: `07_A2SWHK`（影は実物写真の接地影のみ）、`01_Pentagram / homepage_desktop.png`（影なし）。

5. **画像の中に文字を焼き込まない。タイトルと説明はカード/ヒーローの外（下）に置く。**
   なぜ: JP/EN切替で読めなくなる（design-system §5.8 と同じ）。外に置けば言語ごとに差し替えられる。
   根拠: `01_Pentagram / homepage_desktop.png`、`11_Takram / projects_index_desktop.png`（キャプションは画像の下）。例外はロゴが主役のとき。

6. **余白は広く取る。PC+SPの組が地に占める面積は6〜7割まで。**
   なぜ: 余白で静けさを出すのが河野さんの方針。8:5の枠いっぱいに詰めると「情報の塊」に見える。[推測: 6〜7割という数値は観察からの目安で、出典はない]
   根拠: `01_Pentagram / homepage_desktop.png`（Silverlinings は地の中で絵が小さい）、`10_FutureBrand / homepage_desktop.png`。

7. **色は「地1色+作品の色」だけ。サムネ内に新しい色を足さない。**
   なぜ: 一覧に並べたとき、作品ごとの色が際立つ。
   根拠: `01_Pentagram / homepage_desktop.png`、`09_Landor / project_01_milansymphony_desktop.png`（ロゴ1つに地色1色）。

8. **角丸は画面キャプチャにだけ8px（`rounded-media`）。外枠のカード自体は既存の `rounded-card` に従う。新しい値を作らない。**
   なぜ: 既存ルール（§5.6, §5.7）との一貫性。14社も角丸は0か約8pxに収まっている。
   根拠: `04_Collins`、`09_Landor`（約8px）、`12_Zypsy`・`11_Takram`（0）。

9. **タイポは2段のキャプションだけ。タイトル（本文色）+メタ（灰色・小）。装飾書体や大見出しをサムネ内に入れない。**
   なぜ: 作品の画面そのものを読ませる。
   根拠: `07_A2SWHK / work_page_desktop.jpeg`（太字タイトル+通常2行）、`11_Takram`（タイトル+メタ3段）。

10. **PCの画面は「1画面ぶん」だけ切り取る（ファーストビューの上半分など）。ページ全体の縮小画像を置かない。**
    なぜ: 縮小したページ全体は何も読めず、情報量だけが多く見える。切り取れば、中身が1つ読める。[推測: 観察ではなく、Takram/Zypsy の画面が1画面ぶんだけである点からの解釈]
    根拠: `12_Zypsy / work_desktop.png`（Podium のノートPC画面はファーストビューのみ）。

## 5. 河野さんに好みを聞くための質問案

1. 14社のうち、**サムネの見せ方で「これは自分のポートフォリオに近い」と感じる会社**を2社挙げてもらえますか。（候補: A2/SWHK、Takram、01_Pentagram、Zypsy）
2. **PC画面とスマホ画面を同じ画像に入れる**とき、(a) 並べて置く（Zypsy の ZettaJoule 型）、(b) PCだけ大きく見せてSPは詳細ページに回す、(c) 実景のノートPC写真に載せる、のどれが好みですか。
3. 一覧のサムネに**グラデーションや実景の写真があるもの**（Zypsy の Captions、DesignStudio のホーム）は、好みですか、避けたいですか。
